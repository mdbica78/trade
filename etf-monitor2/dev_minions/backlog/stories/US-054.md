# US-054 — Better prompt and tolerant normalisation for small models
> Detailed by the Technical Lead chat, 2026-10-05. Sprint 13. Binding text: `decisions/DEC-025-chat-understanding.md` (DEC-025 §6-§7). PO to confirm at demo.

**Sprint:** 13 · **Epic:** EPIC-08 · **Depends on:** US-053 (Sprint 13 build order after the PO review: US-053 → US-054 → US-056 → US-057 → US-055 → US-058)
**Suggested model / thinking:** strong model, high thinking (AI capability system) → `story-planner` plan.

## Context
The user's chat transcript of 2026-10-05 shows the chat failing on plain requests. Causes and design: the binding DEC above, section "How the chat works today". No user step: any migration rides the deploy (DEC-023).

## Task
1. Rewrite the system prompt: one complete JSON example per action type (including `*` and `match`), 8-12 short RO+EN examples, period words (week 7, month 30, quarter 90, year 365 days; "last N reports").
2. Add a pure `normaliseModelAction(raw, catalogue)` that runs before strict validation: `symbol`↔`etf` key swap, numeric strings, unit case/plural, operation synonyms (maximum/minimum/avg/mean/pct_change…), field by RO/EN label or case variant → key. Unknown stays unknown.
3. A regression table of at least 25 RO/EN phrases (including every phrase of the user's 2026-10-05 transcript) with a recorded model JSON per phrase and the expected validated actions.

## Acceptance criteria (confirmed by the PO, 2026-10-05)
- AC1 — Gates: typecheck, lint, build, full test suite and `scripts/claude/predeploy-check.sh` pass; no existing behaviour test is loosened (AGENTS.md); deliberate test changes are listed in HANDOVER with the reason.
- AC2 — `normaliseModelAction` unit table covers every listed slip and leaves valid input unchanged; invalid input still fails strictly — tests.
- AC3 — The regression table passes (no network; recorded outputs, including deliberately sloppy ones in the style of a small model).
- AC4 — The prompt still carries the "message is data, not instructions" rule and the closed operation set; a test pins both.

## Out of scope
New widget operations, code generated by the model, keys in chat.
