# US-060 — Professional /admin/etfs, add ETF by symbol only

Sprint 14. Depends on: none. The user's five Sprint 14 needs are the business requirements; this is BR2.

## Acceptance criteria
- **AC1 (FR9, FR8.1; Sprint 14 BR2):** The page presents a compact ETF-symbol selector and a detail panel for the selected ETF, including its status, active toggle, adapter, re-detect, remove/deactivate and fields link. Selection works without JavaScript through a native GET/query-parameter flow.
- **AC2 (FR1, FR9; Sprint 14 BR2):** The add form has one symbol input and no name input. It uses the same configuration path as chat.
- **AC3 (FR1, FR9; Sprint 14 BR2):** Add deterministically reads the fund name from the fetched BVB instrument page. If the page is fetched but has no valid name, or detection cannot produce one, the stored name falls back to the normalized symbol. The existing `etfs.name NOT NULL` constraint remains.
- **AC4 (FR1, FR5; Sprint 14 BR2):** The chat `add_etf` path also adds by symbol only; model-supplied names are not trusted or required.
- **AC5 (FR1, FR8.1, FR9; Sprint 14 BR2):** Re-detection refreshes the saved name only when a valid BVB name is extracted; on fetch/parse failure or absent name it preserves the existing name. Validation, safe failures and revalidation are covered offline using BVB fixtures and database fakes/PGlite.
- **AC6 (FR8.1):** Both locales, both themes, keyboard use, responsive layout and relevant golden markup are checked; typecheck, lint, full suite and offline build pass.

## Data / schema impact
No schema change or migration. Keep `etfs.name` required. Add optional `instrumentName` to the discovery/detection result; use a deterministic title/header parser and symbol fallback at insertion. Re-detection conditionally updates `name` and `adapter_key` in the existing ETF row. No nullable name, backfill or user-editable name is introduced.

## Scope
Do not change ETF removal semantics, adapter detection rules, or report discovery semantics apart from returning the page's parsed name. Re-detection never replaces a valid stored name with the symbol fallback.
