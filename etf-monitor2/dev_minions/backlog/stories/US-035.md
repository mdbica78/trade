# US-035 — Adopt the visual layer: lighter trader palette plus light theme, contrast fixes, DEC-020
> Detailed by agent (story-planner), 2026-09-28 — PO to confirm at demo.

**Sprint:** 9 · **Epic:** EPIC-08 · **Depends on:** US-048 (build order only), US-016, US-019, US-024
**Suggested model / thinking:** strong model, high thinking. Complex: every stylesheet token, a theme mechanism in the root layout, a header rework, new contrast and literal-scan tests, and the binding design reference (11 ACs). So it is planned by `story-planner`.

## Context

- **FR15:** a "trader" look, not a near-black one. A lighter dark-slate theme and a light theme, switchable, with WCAG AA contrast. **FR8.2:** charts use a readable palette.
- **DEC-020** (Decided) is the binding text for this story: §1 tokens, §2 themes, §3 contrast, §4 chart colours, §5 positional selectors, §6 deliberate markup changes, §7 scroll wrapper, §8 header, §10 design reference.
- **Design reference** `backlog/home-design/`: the spec's rules 1, 3, 7 and the "Tokens" line, the four PNGs, and `mockup-home.html` (its CSS is the token source: light `:root{--bg:#eef1f6;--panel:#fff;--head:#f5f7fb;--line:#dde3ee;--text:#1b2433;--muted:#5d6b82;--accent:#1f6feb;--gain:#0f8a4b;--loss:#d1323f;--flat:#5d6b82;--hover:#f1f5fd}`, dark `[data-theme=dark]{…}`).
- **What exists** (`backlog/ui-design-adoption.md`, the designer's restyle of 2026-09-28):
  - `app/globals.css` has one dark-only `:root` block with `--bg`, `--bg-panel`, `--bg-elevated`, `--bg-hover`, `--border`, `--border-strong`, `--text`, `--text-muted`, `--text-dim`, `--accent`, `--accent-strong`, `--accent-soft`, `--gain(-soft)`, `--loss(-soft)`, `--warn(-soft)` and `--radius`, plus `html { color-scheme: dark }` and an `@theme inline` block (`--color-background`, `--color-foreground`, fonts).
  - Components use these through Tailwind arbitrary values, e.g. `border-[var(--border)] bg-[var(--bg-panel)]`. Files: `AppHeader`, `EtfDetail`, `FieldChart`, `chat/*`, `admin/*`, `app/health/page.tsx`.
  - `--text-dim #566173` is 2.9:1 on panels. It colours the table headers, flat deltas, stale log entries and the chart tooltip date.
  - `components/FieldChart.tsx` hard-codes `#202836`, `#8a96a8`, `#22d3ee`, `#0a0e14`.
  - Positional selectors carry meaning: `tr[data-run-end="…"] td:nth-child(3)` (operations dashboard run status), and `td:first-child > span:not([class])` (the home table's "extraction unavailable" marker).
  - The home table has no scroll wrapper (`app/page.tsx`), and `table { border-radius }` does not round a `border-collapse` table.
  - `components/AppHeader.tsx` shows the logo+name, then four nav links (icons, labels hidden below `sm`), then `LanguageSwitcher`. It has no active-page state and no theme toggle.
  - `app/layout.tsx` sets no `data-theme` and has no inline script.
- **Tests** render with `renderToStaticMarkup`. There is no DOM test environment (no jsdom/testing-library). Interactive logic lives in pure modules (e.g. `components/chat/chat-state.ts`).
- Product default **P-5** (review §4): with no saved choice, follow the browser; dark slate when the browser says nothing.

## Task

1. **Tokens (DEC-020 §1).** `app/globals.css` gets two blocks with the same custom properties: `:root` (light) and `:root[data-theme="dark"]` (dark slate).
   - Names: `--bg`, `--panel`, `--head`, `--line`, `--text`, `--muted`, `--accent`, `--gain`, `--loss`, `--flat`, `--hover`, `--radius`, `--focus`, `--chart-1` … `--chart-6`.
   - Values: the spec's token line, adjusted where §3 says they fail.
   - `color-scheme` follows the theme.
   - Rename every use across `app/` and `components/`. No alias block survives.
   - Extra tokens (`--warn`, tints, elevated surfaces) follow sprint item **D-5**.
   - Radii (12 px card, 8 px buttons), the system UI font stack, the 15 px base and the 12 px labels follow the spec's token line. The design reference is binding (DEC-020 §10), so the default is the system UI font. Keeping Geist is allowed only for a concrete technical reason (a build or test constraint), recorded as a DEVIATION with that reason. Taste is not a reason.
2. **Themes (DEC-020 §2, P-5).**
   - A pure module (e.g. `lib/theme.ts`) holds the storage key `etf-theme`, the resolver (stored choice → else `prefers-color-scheme` → else dark), and storage read/write inside try/catch.
   - An inline script in `app/layout.tsx`, built from that module, sets `data-theme` on `<html>` before first paint. `<html>` gets `suppressHydrationWarning`.
   - A small client toggle component sits in the header. It has an `aria-label` in RO and EN, flips `data-theme` and stores the choice.
3. **Header (DEC-020 §8, spec rule 1).**
   - App name left, navigation in the middle, theme toggle and RO/EN right.
   - The five items keep their order and message keys: Home, Chat, Administration, System status, and the RO/EN switch.
   - The active page is a filled accent pill, marked with `aria-current="page"` (the hook the style uses).
   - On a phone, the labels collapse to icons (with accessible names) and nothing overlaps at 390 px.
   - `:focus-visible` uses `--focus`.
4. **Contrast test (DEC-020 §3).** A new unit test parses both token blocks out of `app/globals.css` and computes the WCAG ratios.
   - ≥ 4.5:1 for every text/delta colour (`--text`, `--muted`, `--accent`, `--gain`, `--loss`, `--flat`, plus any extra text token per D-5) on `--bg`, `--panel`, `--head` and `--hover`, in both themes.
   - ≥ 3:1 for `--focus` on its surfaces, and for `--chart-1..6` on `--panel`.
   - It fails below the limit, and a self-check proves it fails on a synthetic low-contrast pair.
5. **No colour literal outside the token blocks (DEC-020 §1, §4).** A scan test over `app/**/*.css`, `app/**/*.tsx` and `components/**/*.tsx` fails on a hex, `rgb(`, `rgba(` or `hsl(` literal outside the two token blocks. The same scan fails on any old token name (`--text-dim`, `--bg-panel`, `var(--border)`, `--text-muted`, `--bg-hover`, …, per the plan's rename list).
6. **`FieldChart` colours (DEC-020 §4).** Series, grid, axis text and tooltip use `var(--chart-n)`, `var(--line)`, `var(--muted)` and `var(--panel)` through `style` props, so a theme switch applies without re-rendering the chart. No colour literal is left in the file.
7. **Positional selectors (DEC-020 §5).** Convert the two positional selectors to `data-*` hooks or classes, with no behaviour change:
   - the operations-dashboard run-status cell;
   - the home table's "extraction unavailable" span.
8. **Home table scroll wrapper (DEC-020 §7).** In `app/page.tsx`, the table sits in a wrapper with `overflow-x: auto`. The table gets a `min-width`. Radius and border go on the wrapper, not on `<table>`.
9. **Messages:** the toggle's `aria-label` (and its visible text, if any), in both catalogues.

## Notes for verification

- **Contrast maths.** Use WCAG 2.x relative luminance (sRGB linearisation, `(L1+0.05)/(L2+0.05)`). DEC-020 §3 gives computed guidance values (light `--gain #0b7a42`, `--accent #1a5fd0`; dark `--loss #ff7f8a`), but the test decides. The reviewer re-derives at least one ratio by hand.
- **The literal scan must not be vacuous.** Its self-check feeds it a string with a hex literal outside a token block and expects a failure. The token blocks themselves are the only exempt region.
- **Flash of the wrong theme.** The inline script runs before paint. Its body is a static string built from the theme module, not user input (no injection surface), and it only reads `localStorage` inside try/catch.
- **Hydration.** The toggle's initial render must not assume a theme on the server. The plan says how it reads the current `data-theme` after mount.
- **Header active state.** `AppHeader` is a server component today. Deriving the current path may need a small client part (`usePathname`). If so, the plan says which part is a client component and keeps the rest on the server.
- **Tailwind arbitrary values** such as `bg-[var(--bg-panel)]` are renamed, not removed. The reviewer checks that the rename list in the plan covers every `var(--…)` found in `app/` and `components/` (a grep, not a guess).
- **Design reference.** The reviewer checks that the HANDOVER section has one line per PNG (four lines), and that none says MATCH for a part this story does not own.
- **Manual QA (Codex):** capture `/` at about 1200×560 in light and dark, and at 390 px, and compare the header, the background and the card frame with the PNGs (AC9). Also check that the toggle survives a reload, and a browser with storage blocked.
