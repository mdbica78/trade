# US-005 — Seed the ETF registry and field catalogue

**Sprint:** 1 · **Epic:** EPIC-01 · **Depends on:** US-003
**Suggested model / thinking:** cheap model, low thinking

## Context

The application must support any ETF on BVB, but it needs a starting set and a catalogue describing what the first adapter can extract. Three ETFs share the BRD depositary report format and are seeded here. ICBETNETF is deliberately excluded: it uses a different format and an unresolved download mechanism (Sprint 7).

## Task

Write an idempotent seed script (`pnpm db:seed`) that inserts:

**ETFs** — `adapter_key` = `brd-depositary` for all three:

| symbol | name | bvb_url |
|---|---|---|
| BTBETRETF | Fondul Deschis de Investiții BT Index România ETF BET-TR | https://bvb.ro/FinancialInstruments/Details/FinancialInstrumentsDetails.aspx?s=BTBETRETF |
| TVBETETF | Fondul Deschis de Investiții ETF BET Patria-Tradeville | https://bvb.ro/FinancialInstruments/Details/FinancialInstrumentsDetails.aspx?s=TVBETETF |
| PTENGETF | Fondul Deschis de Investiții ETF Energie Patria-Tradeville | https://bvb.ro/FinancialInstruments/Details/FinancialInstrumentsDetails.aspx?s=PTENGETF |

**Field catalogue** — all with `adapter_key` = `brd-depositary`:

| field_key | label_ro | label_en | unit |
|---|---|---|---|
| net_asset | Activ net | Net asset | RON |
| units_in_circulation | Unități de fond în circulație | Units in circulation | count |
| units_held_individuals | Unități deținute de persoane fizice | Units held by individuals | count |
| units_held_legal_entities | Unități deținute de persoane juridice | Units held by legal entities | count |
| nav_per_unit | Valoare unitară a activului net (VUAN) | Net asset value per unit | RON |
| investors_total | Număr investitori | Number of investors | count |
| investors_individuals | Investitori persoane fizice | Individual investors | count |
| investors_legal_entities | Investitori persoane juridice | Legal-entity investors | count |

**Tracked fields** — for each seeded ETF, track `units_in_circulation` (display_order 0) and `nav_per_unit` (display_order 1). The rest stay available but untracked, so the user can enable them later.

**Settings** — insert the single row with `id = 1`, `default_locale = 'ro'`, everything else null.

Running the script twice must not create duplicates or fail.

## Acceptance criteria

- **AC1** — `pnpm db:seed` inserts exactly the three ETFs, eight catalogue fields, six tracked-field rows, and one settings row.
- **AC2** — Running the seed a second time changes nothing and exits successfully (idempotent, via upsert on the unique keys).
- **AC3** — The seed reads `DATABASE_URL` from the environment; no connection string is committed.
- **AC4** — A unit test asserts the seed data set is internally consistent: every `field_key` in tracked fields exists in the field catalogue, and every ETF references an adapter key present in the catalogue. This test runs against the seed definition, not a live database.
- **AC5** — `pnpm test`, `pnpm lint`, and `pnpm build` pass.

## Out of scope

- No ICBETNETF.
- No UI for managing any of this (Sprint 5).
- No report data — only registry and configuration.

## Notes for verification

The Romanian labels are what appear in the interface, not what appears in the PDF. Mapping PDF label text to `field_key` is the adapter's job in Sprint 2, deliberately separate, so that a change in the report's wording does not require changing the UI.
